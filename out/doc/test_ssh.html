test_ssh - Loopback tests for the ssh module.

Each test starts an in-process ssh.Server on an ephemeral port (port=0) and
connects an ssh.Client to it over 127.0.0.1. Ephemeral ports make the tests
safe to run concurrently (acton test stress).

_test_echo_payload(t: testing.EnvT)

Stream 256 KiB through a server echo and verify integrity.

Payload size is kept moderate so the test stays well within the test
timeout under `acton test stress` with many concurrent workers; raw
throughput is covered by the bench_echo program.
