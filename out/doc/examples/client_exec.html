examples.client_exec - Example: connect to an SSH server, run a command, print its output.

Usage:
client_exec HOST USER CMD [PORT] [PASSWORD]

- Authenticates with PASSWORD if given, otherwise with the key
~/.ssh/id_ed25519 (publickey).
- Host key checking here is intentionally permissive (accept any key) so the
example works against an unknown server; a real client should verify the
host key against known_hosts or a pinned fingerprint.

Examples:
client_exec 127.0.0.1 admin "uname -a" 2222 secret
client_exec example.com alice "uptime"
