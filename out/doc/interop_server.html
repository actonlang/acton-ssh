interop_server - Interop test server: serves exec and subsystem requests for an OpenSSH client.

Prints "PORT <n>" once listening. Serves until killed.

exec "ping" -> writes "pong
", exit status 0
exec anything else -> writes error to stderr, exit status 127
subsystem "echo" -> echoes all received data back, closes on client EOF

Each channel owns its own lifecycle. exec channels are fully driven by the
on_exec handler and ignore stdin EOF (the command does not read stdin). The
echo subsystem closes only when the client signals EOF, so a piped
`ssh -s ... echo` terminates cleanly.
